<details>
<summary><b>🧠 01 — Brain Tumor Classification & Segmentation &nbsp;|&nbsp; Acc 97.8% · Dice 0.887</b></summary>
<br/>

> *Automated multi-class tumor detection with pixel-level MRI segmentation — built for radiologist-assistive clinical workflow.*

**Tumor Classes:** Glioma · Meningioma · Pituitary Tumor · No Tumor

**Architecture Pipeline:**
- **Stage 1 — Classification:** `EfficientNet-B4` pretrained on ImageNet → Global Average Pool → Dropout → FC head → 4-class Softmax
- **Stage 2 — Segmentation:** `U-Net` with residual skip connections → combined Dice + BCE loss → binary tumor mask overlay
- **Stage 3 — Explainability:** `Grad-CAM` attention heatmaps rendered on MRI slices for radiologist trust & audit trail

**Benchmark Results:**

| Model | Accuracy | F1-Score | AUC-ROC |
|-------|----------|----------|---------|
| ⚡ **EfficientNet-B4** | **97.8%** | **0.977** | **0.995** |
| ResNet-50 | 95.2% | 0.951 | 0.987 |
| VGG-16 | 93.6% | 0.934 | 0.981 |
| U-Net Segmentation | Dice **0.887** | IoU **0.798** | — |

**Stack:** `PyTorch` `timm` `EfficientNet-B4` `U-Net` `Albumentations` `MLflow` `Grad-CAM` `ONNX`

</details>
